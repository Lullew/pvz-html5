# 草坪保卫战（HTML5 塔防游戏）

一个《植物大战僵尸》玩法的原创网页游戏：种植植物、收集阳光、抵御僵尸、小推车救场、**15 关逐关推进**。每过一关难度系数翻倍，同时玩家获得同步增强的强力 buff；第 3/6/9/12 关为 Boss 关，第 15 关为强化终极 Boss 决战。全部美术为 Canvas 自绘几何图形，音效为 WebAudio 程序化合成，**不含任何官方版权素材**。

## 一、运行方式

游戏使用原生 ES6 模块，浏览器安全策略下 `file://` 直接打开会拦截模块加载，请用任意静态服务器运行：

```bash
# 方式一：Python（任选其一）
python -m http.server 8000

# 方式二：Node
npx --yes http-server -p 8000
```

然后浏览器访问 `http://localhost:8000/`。无需构建、无后端依赖。

## 二、操作说明

### 桌面端

| 操作 | 说明 |
|---|---|
| 鼠标点击卡牌 | 选择植物（数字键 1–6 快捷选卡，再按一次取消） |
| 鼠标点击格子 | 种植；绿色预览可种、红色预览不可种 |
| 点击阳光 | 收集，单枚价值随关卡增长（25 起，最高 95） |
| 右上角按钮 / Esc | 暂停与继续 |

### 移动端

- 触摸点选卡牌与格子完成种植，触摸收集阳光，建议横屏游玩。
- 界面自动等比缩放适配屏幕。

## 四、难度与 Buff 系统

每关开局横幅显示当前主题 buff，全部倍率由 `src/config/buffs.js` 的 `getModifiers(n)` 计算，关卡 n（1..15）的难度系数为 **2^(n-1)**。

### 僵尸侧（难度增长）

| 倍率 | 公式 | 第 15 关值 |
|---|---|---|
| 血量倍率 | 2^(n-1) | ×16384 |
| 速度倍率 | min(2, 1+0.07(n-1)) | ×2 |
| 数量倍率 | 1+0.35(n-1) | ×5.9（单波封顶 24 只） |

### 植物侧（强力 buff，与难度对冲）

| 倍率 | 公式 | 第 15 关值 |
|---|---|---|
| 伤害倍率 | 2^(n-1) | ×16384（与僵尸血量同步，所需命中次数不变） |
| 攻速倍率 | min(1.8, 1+0.06(n-1)) | ×1.8 |
| 生命倍率 | 1.5^(n-1) | ×291.9 |
| 卡牌冷却倍率 | max(0.4, 1-0.04(n-1)) | ×0.4 |
| 初始阳光 | 50+25(n-1) | 400 |
| 单枚阳光价值 | 25+5(n-1) | 95 |
| 天降阳光间隔 | max(4, 10-0.4(n-1)) | 4s |
| 冰冻减速 | 最低降至 30% 速度，持续最长 8s | 30% / 8s |

### 主题 buff 名

基础防线、锋利茎叶、急速光合作用、阳光丰收、坚韧树皮、冰霜强化、火药改良、根系网络、机械克星、自然之怒、生命涌流、时空加速、太阳风暴、不败防线、终极进化。

## 五、植物与僵尸

### 植物（基础值，实际随关卡乘算倍率）

| 植物 | 消耗 | 冷却 | 生命 | 机制 |
|---|---|---|---|---|
| 向日葵 | 50 | 7.5s | 300 | 每 24s 产阳光（首次 8s），价值随关卡增长 |
| 豌豆射手 | 100 | 7.5s | 300 | 每 1.4s 发射豌豆，伤害 20 |
| 坚果墙 | 50 | 30s | 4000 | 高血量防御，三档受损外观 |
| 寒冰射手 | 175 | 7.5s | 300 | 伤害 20 并减速，强度/时长随关卡增强 |
| 樱桃炸弹 | 150 | 50s | 1 | 1.2s 引爆，3×3 范围 1800 伤害 |
| 土豆雷 | 25 | 30s | 300 | 14s 武装，接触即爆，1800 伤害 |

### 僵尸（基础值，实际随关卡乘算倍率）

| 僵尸 | 生命 | 速度 | 机制 |
|---|---|---|---|
| 普通僵尸 | 200 | 0.28 格/s | 基础单位 |
| 路障僵尸 | 560 | 0.28 格/s | 路障护甲 360，先毁护甲 |
| 铁桶僵尸 | 1300 | 0.28 格/s | 铁桶护甲 1100 |
| 撑杆僵尸 | 400 | 0.42 格/s | 遇第一株植物撑杆跳越一次，之后降速 |

### Boss（僵王博士机甲）

- 占 2×2 格、独立血条、独立死亡判定；小推车不能秒杀，仅造成 500 固定伤害。
- 三阶段（血量 100%/66%/33% 阈值），阶段转换有 2.5s 预警且减伤 50%。
- 五技能：召唤僵尸（数量上限随关卡提升，最高 20 只）、冰球（摧毁植物并停火）、火球（灼烧）、砸地（毁一列+震屏）、冲撞（毁两列+强震）；所有技能均有地面预警与冷却。
- 每个 Boss 关血量随难度翻倍；**第 15 关终极 Boss 血量再 ×3、技能冷却再 ×0.8**，入场横幅为“最终决战开始！”。

## 六、关卡与配置说明

全部数值数据驱动，逻辑代码不写死数值：

| 文件 | 内容 |
|---|---|
| `src/config/buffs.js` | 总关卡数、主题 buff 名、`getModifiers(n)` 全部难度/增幅公式 |
| `src/config/balance.js` | 网格尺寸、阳光、子弹、减速、小推车、震屏等全局常量 |
| `src/config/plants.js` | 六种植物属性与卡牌顺序 |
| `src/config/zombies.js` | 四种僵尸属性 |
| `src/config/boss.js` | 基础 Boss 配置与 `makeBossConfig(n)` 关卡 Boss 工厂 |
| `src/config/levels.js` | 前 3 关手工布局，4–15 关程序化生成的波次与刷怪配置 |

调整难度只需修改配置，例如改 `buffs.js` 中的公式，或在 `levels.js` 调整生成参数。

## 七、调试模式

- URL 加参数：`http://localhost:8000/?debug=1`，游戏中也可按 `~` 切换。
- 显示：网格线、全部碰撞箱、FPS、当前 buff 与难度系数、倍率摘要、波次倒计时、天降阳光计时、Boss 阶段与技能冷却、对象池统计。
- 浏览器控制台可通过全局 `window.__game` 访问游戏实例检查状态。

## 八、存档

`localStorage`（key `lawn_defense_save_v1`）保存关卡解锁进度（顺序解锁，上限 15）与音效开关，清除浏览器数据即重置。

```
├─ index.html / styles.css

   ├─ main.js                入口
   ├─ core/                  游戏循环、状态机、输入、对象池、碰撞、震动

   └─ debug/                 调试覆盖层
```

## 十、已知限制

1. 仅实现横屏草坪场景，未做夜间/泳池等场景。
2. 音效为合成占位音色，音乐曲目未实现。
3. 高关卡数值为指数级（第 15 关难度系数 16384），属设计要求的强对冲体验。
4. 未接入 AI 大语言模型。

## 十一、后续扩展点

- 新植物/新僵尸：新增配置 + 一个自绘函数即可，无需改系统逻辑。
- 更多关卡：在 `buffs.js` 调整 `TOTAL_LEVELS` 与公式，`levels.js` 生成器自动扩展。
- 可选 AI 大模型扩展（仅用于 Boss 台词，不参与伤害判定）：需异步调用、超时降级与内容过滤；API Key 不得硬编码前端，应走安全代理；断网时游戏仍可完整通关。
